## Цель и архитектура
- Стек: React + TypeScript + Vite, сборка в статичные файлы.
- Хостинг: GitHub Pages. В vite.config нужен base: '/<имя-репо>/' (имя репо пока max-apocalypse), все пути к картинкам строим через import.meta.env.BASE_URL, никаких абсолютных '/assets/...'.
- Telegram: бот только открывает игру как Mini App по HTTPS-ссылке на Pages. Telegram-слой (WebApp.ready/expand, тема, кнопка «назад», id игрока) держим отдельным модулем.
- Мультиплеер: Firebase Firestore, без своего сервера. Комната coop/<код>. Хост прогоняет действия через движок и записывает состояние, остальные игроки только отправляют свои действия.
- Движок: чистая функция reduce(state, action) без мутаций, сразу под 2–4 игроков (массив игроков, позиции, чья очередь). Состояние партии должно помещаться в один документ Firestore.
- Карты описываем данными (эффекты, числа) в одном месте, чтобы ребаланс был правкой цифр.
- UI в первую очередь для вертикального экрана телефона.

## Ограничения Telegram WebView
- Не использовать: Path2D(svgString), color-mix, CSS.escape, background-attachment: fixed.
- Скачивание файлов через blob не работает, только WebApp.downloadFile.
- При перерисовке сохранять позицию прокрутки.
- Не делать двойных анимаций, иначе экран мерцает.
